{# email shortcode — produces a mailto link with the address lightly obfuscated in the visible text. Each "@" is rendered as @ and each "." as . via HTML numeric character references; this defeats naive regex scrapers while remaining transparent to humans, screen readers, and the mailto: href itself (kept literal for one-click "compose new mail" support). #} {%- set addr = config.extra.email -%} {%- set display = addr | replace(from="@", to="@") | replace(from=".", to=".") -%} {{ display | safe }}
